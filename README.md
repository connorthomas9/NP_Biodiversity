## Overview
The goal of this project is to analyze biodiversity data from the National Parks Service, particularly around various species observed in different national park locations.

This project will scope, analyze, prepare, plot data, and seek to explain the findings from the analysis.

The primary analysis takes place in the `biodiversity.ipynb` Jupyter Notebook file

The datasets used for this project are the `observations.csv` and `species_info.csv` files, and come by way of `Codecademy.com`

This project comes by way of `Codecademy.com` and has been recreated from scratch in order to demonstrate knowledge of applied usage of a variety of data anlaysis techniques
